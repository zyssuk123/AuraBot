Docker Configuration
Quick Start
The container is pre-configured for Windows GUI output. VcXsrv must be running before starting the container.
docker-compose.yml
# Services configuration services: aurabot-detection: build: context: . dockerfile: Dockerfile container_name: aurabot-detection privileged: true environment: - DISPLAY=host.docker.internal:0.0 - GUI_ENABLED=true - CAMERA_ENABLED=true - ARDUINO_ENABLED=false volumes: - ./data:/app/data - ./temp:/app/temp - /tmp/.X11-unix:/tmp/.X11-unix:rw
bash
# Start the application docker-compose up -d --build aurabot-detection # View live logs docker logs -f aurabot-detection # Stop the application docker-compose down
